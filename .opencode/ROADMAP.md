# ROADMAP.md

Development roadmap for the Eaz Community project.

Milestones follow the Development Order defined in PROJECT_SPEC.md. Each milestone must be fully complete (Backend, Mobile, Database, API, Socket, Validation, Testing, Documentation, Review) before the next begins.

---

## Phase 0: Foundation

- Monorepo workspace setup
- Backend workspace initialization (Express.js + TypeScript)
- Frontend workspace initialization (React Native + Expo)
- Docker infrastructure (MongoDB, Redis, backend, frontend)
- CI/CD with GitHub Actions
- Environment configuration and validation

## Phase 1: Core Messaging

- Authentication (registration, login, OTP, refresh tokens)
- User profiles and media upload
- Private chat with read receipts and delivery status
- Group chat
- Socket.IO realtime infrastructure with Redis adapter

## Phase 2: Community Features

- Communities
- Channels
- Stories
- Push notifications (FCM)
- In-app notification center

## Phase 3: Realtime Calls

- Voice calls
- Video calls

## Phase 4: Marketplace & Payments

- Marketplace (products, orders, inventory)
- Business pages
- Paystack payments and checkout
- Order webhooks

## Phase 5: Intelligence

- AI assistant
- Translation
- Message summary
- Smart reply

## Phase 6: Platform & Admin

- Business accounts
- Admin dashboard
- Reports and moderation
- Settings and privacy controls

## Phase 7: Scale & Release

- Analytics
- Performance and load testing
- App Store and Play Store releases
- Production deployment, monitoring, logging, and backups
